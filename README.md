## Max's Auto Dealership

https://a4-maxgambino.onrender.com

This is a car dealership inventory manager refactored from Assignment 3 into React components. The main inventory page (data table and car form) was rebuilt using React with Vite as the build tool, while the login page was kept as plain HTML. The server-side Express + MongoDB backend remains unchanged. React improved the development experience.  Component state and props made the form/table interaction much cleaner than manual DOM manipulation, and Vite's hot module replacement made iterating on the UI fast and painless.
